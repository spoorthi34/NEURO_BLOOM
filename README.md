Create a modern AI-powered learning platform called "NeuroLearn AI".

The platform helps neurodivergent students (ADHD, Dyslexia) understand complex educational material by transforming uploaded learning content (PDF, PPT, text) into simplified micro-learning cards.

The interface must be professional, futuristic, calm, and highly polished.

• Soft glassmorphism UI

• Rounded UI components

• Responsive layout (desktop + tablet + mobile)

BACKGROUND STYLE

Background must feel peaceful and modern.

Use:

PLATFORM STRUCTURE

The platform must contain these main parts:

1. Landing Page

2. Login Page

3. Signup Page

4. User Dashboard

5. AI Learning Workspace

------------------------------------------------

LANDING PAGE

Landing page should clearly explain the platform.

Navigation Bar (Top):

• Logo (NeuroLearn AI)

• Home

• Features

• About Us

• Contact Us

• Login Button

Hero Section:

Large heading:

"AI-Powered Learning for Every Mind"

Subheading:

"Simplifying education for neurodivergent learners."

CTA Buttons:

• Get Started

• Try Demo

Add a simple animated illustration showing:

complex text → simplified learning cards.

Features Section:

Show 4 feature cards:

• AI Content Simplification

• Dyslexia Reading Mode

• ADHD Focus Mode

• Audio Learning

About Section:

Short description of the mission.

Contact Section:

Simple contact form.

------------------------------------------------

LOGIN PAGE

Create a clean authentication page.

Layout:

Centered glass-style login card.

Fields:

• Email

• Password

Buttons:

• Login

• Continue with Google

Below login:

"Don't have an account? Sign Up"

------------------------------------------------

SIGNUP PAGE

Create a signup page similar to the login page.

Fields:

• Full Name

• Email

• Password

• Confirm Password

Buttons:

• Create Account

• Continue with Google

After successful signup/login → redirect to Dashboard.

------------------------------------------------

USER DASHBOARD

The dashboard should feel like a personalized AI learning environment.

Dashboard Sections:

1. Welcome Panel

Show greeting:

"Welcome back, [User Name]"

Show learning progress indicator.

2. Upload Learning Material

Allow user to upload:

• PDF

• PPT

• Text

Files should be processed by AI.

------------------------------------------------

AI CONTENT PROCESSING

When the user uploads a PDF or PPT:

The AI must extract the content from the uploaded file.

IMPORTANT RULE:

Generated learning material must only be based on the uploaded document.

Do NOT generate unrelated content.

------------------------------------------------

AI LEARNING TRANSFORMATION

After processing the file:

Transform the content into:

• Micro learning cards

• Short explanations

• Highlighted keywords

Cards should appear dynamically with animation.

Each card should contain:

• Concept title

• 1–2 sentence explanation

• simple icon

------------------------------------------------

VISUAL LEARNING CARDS

Cards should appear in a floating layout.

Cards animate outward from the center.

Hover interaction:

• expand card

• show deeper explanation

------------------------------------------------

FOCUS MODE (ADHD SUPPORT)

Add a Focus Mode toggle.

When enabled:

• background becomes softer

• only one learning card is highlighted

• other elements fade

This helps ADHD students focus.

------------------------------------------------

DYSLEXIA MODE

Add Dyslexia Reading Mode.

When activated:

• switch to dyslexia-friendly font

• increase line spacing

• improve word spacing

------------------------------------------------

AUDIO LEARNING MODE

Allow students to listen to the content.

Features:

• text-to-speech

• play / pause

• adjustable speed

------------------------------------------------

AI STUDY AGENTS

Implement AI agents that assist the student.

Agents include:

1. Content Simplifier Agent

Simplifies complex text.

2. Concept Generator Agent

Breaks content into concepts.

3. Quiz Generator Agent

Creates short quiz questions.

4. Learning Coach Agent

Suggests what to study next.

------------------------------------------------

MICRO BREAK TIMER

Add a Focus Timer.

Example:

25 minutes study

5 minutes break

Show timer as circular progress animation.

------------------------------------------------

AI PROGRESS TRACKER

Track:

• concepts completed

• study time

• quiz accuracy

Display progress with animated graphs.

------------------------------------------------

USER EXPERIENCE GOAL

The platform should feel like:

• an intelligent AI learning assistant

• a calm digital study space

• visually impressive for hackathon judges

Design must be polished, minimal, and innovative.

Avoid clutter and unnecessary information.

Focus on clarity, accessibility, and AI-powered learning.
