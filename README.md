## 📖 Overview

**NEURO_BLOOM** (Dr. Bloom) is an adaptive, sensory-friendly educational platform built to transform dense, complex learning material into calm, focused, and intuitive micro-learning experiences. Tailored specifically for learners with ADHD and Dyslexia, the platform replaces cognitive overload with visual clarity, active recall, and sensory audio pacing.

## ✨ Key Features

1. **Visual Concept Mind Maps**: Dynamic interactive SVG node graphs connecting concepts visually, eliminating walls of text.
2. **Everyday Analogy Engine (ELI10)**: Translates dry technical jargon into intuitive metaphors (Container Ports, Accordion Highways, Air Traffic Controllers).
3. **Active Recall Micro-Quizzes**: Self-testing flashcards embedded directly into concept cards for instant feedback.
4. **Bionic Reading Mode**: Fixation-guided reading that bolds initial letters to dramatically boost reading comprehension for ADHD minds.
5. **Dyslexia Accommodations**: High-contrast Lexend geometric font and subtle **B / D** letter color distinction to prevent letter flipping.
6. **ADHD Focus Spotlight**: Dims peripheral distractions to focus on one concept chunk at a time.
7. **Sensory Sprint Timer**: Built-in 25-minute Pomodoro focus timer with automated break reminders.
8. **Dual Mode Experience**: Instant Sun ☀️ / Moon 🌙 toggle between high-contrast light mode and deep space dark mode.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/spoorthi34/NEURO_BLOOM.git

# Navigate into the folder
cd NEURO_BLOOM

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:8080/` in your browser.

---

## 📦 Production Build

```bash
npm run build
```
Build output is generated inside the `dist/` directory, ready for Netlify or Vercel deployment.
